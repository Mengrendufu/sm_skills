# Show Me

让用户通过 HTML 看懂当前问题。先确定要说明什么，再选择表达和工具。

- 从当前讨论和材料中找出要回答的问题；区分已知事实、设计方案与示意假设。
- 选择能说明问题的最简单表达：关系用图，差异用对比，变化用图表或交互。用户指定的表达方式优先。
- 直接生成 HTML/CSS/SVG，或按需使用绘图工具；Mermaid、PlantUML 只是可选工具，不限定图表类型。
- 将结果写成可直接打开的 HTML，配上必要的标题、图例和说明。大图保证可读、可滚动；缩放、切换和操作仅在有助理解时加入。
- 优先内联资源；依赖本地文件时一同交付并使用相对路径。依赖联网或服务时说明打开条件。
- 在可用浏览器中检查实际渲染、布局和交互，修正空白、裁切及脚本错误；无法检查时如实说明验证范围。
- 交付 HTML 链接和一句阅读提示；需要配套资源时说明哪些文件须一起保留。

## 按需使用的工具

- [Mermaid](tools/mermaid/TOOL.md)：文本图表；已有脚本可生成带缩放、平移和源码开关的查看器。
- [PlantUML](tools/plantuml/TOOL.md)：UML 等图形；先渲染为 SVG，再放入 HTML。

## 文件输出

未明确指定落地路径时，所有新生成文件（包括代码、笔记、报告及配套资源）写入当前所在系统的临时目录：Unix 使用 `$TMPDIR`，为空则 `/tmp`；Windows 使用 `%TEMP%`。在其下创建本任务独立子目录（下文 `<tmp-task-dir>`），返回文件绝对路径；不以当前工作区作为默认输出目录。用户明确指定路径时遵循指定。
