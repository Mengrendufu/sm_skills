# 契约检查模式

谓词写结构关系，不写语言。对上结构再选检查；对不上就不是契约。

## 世界失败 / 契约失败

| 现象     | 世界失败               | 契约失败                         |
| ---      | ---                    | ---                              |
| 空       | 外部还没提供成员       | 内部协议已保证此时必有成员       |
| 满       | 外部灌入超过吸收能力   | 内部生产者被设计为不可能写满     |
| 越界     | 游标来自未信任输入     | 游标由本结构推出，却落在窗口外   |
| 未绑定   | 对端尚未给出身份       | 公开操作要求已绑定，内部仍未绑定 |
| 未知分支 | 外部编码不在约定集合   | 内部模型已穷尽，仍落到「其他」   |

## `REQUIRE`

| 场景       | 契约                                      |
| ---        | ---                                       |
| 准入形态   | 形态 = 该操作所要求的那一种               |
| 成员资格   | 身份 ∈ 成员集                             |
| 有界写入   | 占用 < 容量                               |
| 独占别名   | 位置甲.身份 ≠ 位置乙.身份                 |
| 句柄已绑定 | 句柄已绑定 ∧ 目标仍是成员                 |

## `ENSURE`

| 场景     | 契约                                                          |
| ---      | ---                                                           |
| 基数变化 | 离开时.占用 = 进入时.占用 ± 1                                 |
| 身份去留 | 加入 ⇒ ∈ 成员集；移出 ⇒ ∉ 成员集；转移 ⇒ 源不持有 ∧ 宿持有    |
| 可见效果 | 命令所宣布的结构关系在出口为真                                |

## `INVARIANT`

公开操作括号内允许暂时为假；两端必须为真。

| 场景         | 契约                                      |
| ---          | ---                                       |
| 计数一致     | 占用 = 成员数                             |
| 双向承认     | 父含此 ⇔ 此.父 = 父                       |
| 空与端点     | 空 ⇔ 端点未绑定；¬空 ⇒ 端点 ∈ 成员集      |
| 占用与容量   | 0 ≤ 占用 ≤ 容量                           |
| 互斥模态     | 恰好一个模态为真                          |
| 序关系       | ∀ 相邻成员：序(左, 右)                    |
| 边不悬空     | ∀ 边：终点 ∈ 节点集                       |

## `ASSERT`

没有更合适的主人时才用。

| 场景       | 契约                            |
| ---        | ---                             |
| 搜索必中   | 查找结果已绑定                  |
| 算法窗口   | 游标 ∈ 当前窗口                 |
| 标签与载荷 | 标签 = T ⇒ 载荷符合 T 的形状    |
| 拆步中点   | 下一步所依赖的局部关系为真      |
| 循环保持   | 回边前：循环所维持的关系        |

## `ERROR`

| 场景           | 契约                                  |
| ---            | ---                                   |
| 穷尽分派剩余臂 | 当前情形 ∈ 已声明的完备集合           |
| 禁止的刺激     | 当前模态允许该刺激                    |
| 初始化后未成形 | 初始化路径结束 ⇒ 公开不变量已成立     |

## `ALLEGE`

| 场景         | 契约                                               |
| ---          | ---                                                |
| 检查即材料   | 同对应检查，但求值不可剥掉（长度、摘要、派生索引） |
