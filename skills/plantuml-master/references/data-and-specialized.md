# Data and Specialized

Covered: Entity/Chen ER, JSON, YAML, MindMap, WBS, ArchiMate, Salt/Wireframe, Ditaa, Regex

## Routing

- **Entity** — conceptual/logical ER. Use Chen ER only when explicitly asked.
- **JSON / YAML** — visualize structured documents/configs. Preserve keys; summarize huge payloads.
- **MindMap** — concept hierarchy, brainstorming.
- **WBS** — deliverable/work breakdown, project decomposition.
- **ArchiMate** — enterprise architecture viewpoints. Confirm layer if unclear. Fall back to Component/Deployment.
- **Salt** — UI mockups, forms, low-fidelity wireframes.
- **Ditaa** — ASCII art diagram rendering.
- **Regex** — visual regex explanation.

## Cross-routing

Favor **Class** for implementation-focused schemas (not ER).
Favor **Component / Deployment / C4** for system architecture (not ArchiMate by default).
