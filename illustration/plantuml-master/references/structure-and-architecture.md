# Structure and Architecture

Covered: Class, Object, Component, Deployment, Package

## Routing

- **Class** — domain model, APIs, type relationships, inheritance, interfaces.
- **Object** — runtime instance snapshots, object graphs. Not for type design.
- **Component** — services, modules, libraries, adapters, ports, dependency direction.
- **Deployment** — nodes, containers, artifacts, infrastructure, runtime placement.
- **Package** — source/module layering and import/dependency constraints.

## Cross-routing

Favor **C4-PlantUML** when the user wants C4 levels.
Favor **Sequence** when the main point is message order.
Favor **Activity** when the main point is process branching.
Favor **Entity** when the request is data modeling / ER.
